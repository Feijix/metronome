Gap Metronome Refactor - Implementation Plan

 Overview

 Transform the Gap Metronome app into a mobile-first, GapClick-inspired design with enhanced audio synthesis, expanded subdivisions, and a comprehensive settings system.

 Key Changes Summary

 - Layout: Large central play button (~40% width), gradient background (green→blue), mobile-first design
 - Subdivisions: Expand from [1,2,4] to [1,2,3,4,6,8,12] with musical symbol notation
 - Audio: 7 synthesized sounds (Clave, Digital, Rimshot, Agogo, Hi-hat, Kick, Cowbell)
 - Settings: Slide-up panel with sound selector, accents, flash toggle, wake lock, and presets
 - Bar Range: Limit Click/Gap bars from 1-16 to 1-8

 PHASE 2: Audio Synthesis System

 Goal: Implement 7 synthesized sounds using Web Audio API

 New Files:
 - js/core/audio/SoundFactory.js - Factory pattern for sound selection
 - js/core/audio/synthesizers/ClaveSynthesizer.js - Wood block (dual oscillator)
 - js/core/audio/synthesizers/DigitalSynthesizer.js - Sharp sine beep
 - js/core/audio/synthesizers/RimshotSynthesizer.js - Noise burst + tone
 - js/core/audio/synthesizers/AgogoSynthesizer.js - Two-tone FM synthesis
 - js/core/audio/synthesizers/HiHatSynthesizer.js - High-pass filtered noise
 - js/core/audio/synthesizers/KickSynthesizer.js - Low sine sweep + click
 - js/core/audio/synthesizers/CowbellSynthesizer.js - Metallic FM synthesis

 Synthesizer Interface:
 Each synthesizer must implement:
 - playAccent(startTime) - Beat 1 sound (highest volume/frequency)
 - playQuarter(startTime) - Quarter beat sound (medium)
 - playSubdivision(startTime) - Subdivision sound (lowest)

 MetronomeAudio.js Refactor:
 - Add setSoundType(type) method
 - Use SoundFactory.createSynthesizer(soundType, audioContext)
 - Update playClick() to delegate to current synthesizer
 - Remove old createAndPlayOscillator() and getClickParameters()

 Sound Design Specs:
 - Clave: Dual osc (800Hz+1200Hz accent), single tone (quarter/sub)
 - Digital: Pure sine (1400/1100/900Hz), sharp attack/decay
 - Rimshot: White noise burst + low tone (200/180/160Hz)
 - Agogo: FM synthesis (carrier 880/740/620Hz, ratio 3.2)
 - Hi-hat: High-pass filtered noise (5-7kHz cutoff)
 - Kick: Low sine sweep (60→40Hz) + click transient
 - Cowbell: FM dual carrier (540+800Hz accent, ratio 5.1)

 Testing: Manual test page with buttons for each sound, verify timing precision

 Risk Mitigation

 High Risk:

 - Audio Synthesis (complex, timing-critical)
   - ✓ Start with simplest sounds (Clave, Digital)
   - ✓ Extensive manual testing with metronome reference
 - Layout Redesign (breaking changes to entire UI)
   - ✓ Backup old HTML/CSS before changes
   - ✓ Incremental testing (one section at a time)
   - ✓ Visual regression screenshots

 Medium Risk:

 - Browser Compatibility (Wake Lock API, scroll snap)
   - ✓ Feature detection with graceful fallbacks
   - ✓ Test on iOS Safari, Android Chrome, desktop browsers

 Low Risk:

 - State Management (new properties)
   - ✓ Validation in setters, defaults in loadPreset
   - ✓ Thorough unit testing

 Notes

 - Musical symbols may render differently across fonts/browsers - test extensively
 - Wake Lock API only works on HTTPS (development exception for localhost)
 - Scroll snap CSS may need vendor prefixes for older browsers
 - Large synthesizer files increase initial bundle size - consider code splitting in future
 - Keep sw.js cache list updated as files are added
